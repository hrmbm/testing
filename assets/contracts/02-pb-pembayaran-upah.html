Pasuruan tahun {{tahun_umk_sekarang}}, yang dituangkan dalam bentuk Perjanjian Bersama ( PB ) dengan kronologis permasalahan serta ketentuan – ketentuan sebagai berikut :

  1. Bahwa Pihak Pertama adalah perusahaan yang bergerak dalam bidang {{bidang_usaha_pb}}, sedangkan Pihak Kedua adalah pekerja pada Pihak Pertama.
  2. Bahwa hubungan kerja antara Pihak Pertama dengan Pihak Kedua telah berjalan secara harmonis dalam kemitraan kerja.
  3. Bahwa pada perkembangan selanjutnya, setelah Upah Minimum Kabupaten / Kota ( UMK ) Kab. Pasuruan tahun {{tahun_umk_lalu}} sebesar Rp {{umk_lalu}},- ( Terbilang : {{umk_lalu_terbilang}} ) menjadi Upah Minimum Kabupaten / Kota ( UMK ) Kab. Pasuruan tahun {{tahun_umk_sekarang}} sebesar Rp. {{umk_sekarang}},- ( Terbilang : {{umk_sekarang_terbilang}} ), maka Pihak Pertama menyatakan dirinya tidak mampu untuk melaksanakan Upah Minimum Kabupaten / Kota ( UMK ) Kab. Pasuruan tahun {{tahun_umk_lalu}} tersebut.
  4. Bahwa meskipun Pihak Pertama merasa tidak mampu melaksanakan ketentuan Upah Minimum Kabupaten / Kota ( UMK ) Kab. Pasuruan tahun {{tahun_umk_sekarang}}, akan tetapi Pihak Pertama tetap membayar Upah kepada Pihak Kedua sesuai dengan Keputusan Gubernur Jawa Timur, Nomor : {{no_sk_gubernur}} tentang Upah Minimum Kabupaten / Kota di Jawa Timur Tahun {{tahun_umk_sekarang}}, namun agar Pihak Pertama tetap bisa eksis menjalankan usahanya dan Para Karyawan juga tetap mendapatkan pekerjaan, maka Para Pihak sepakat untuk melaksanakan pembayaran upah tersebut dengan cara :
    1. Secara tunai sebesar Rp {{gaji_tunai}},- ( Terbilang : {{gaji_tunai_terbilang}} ) dalam setiap bulannya, dan
    2. Kekurangannya sebesar Rp {{selisih_hutang}},- ( Terbilang : {{selisih_hutang_terbilang}} ) disepakati menjadi hutang Pihak Pertama kepada Pihak Kedua.
  5. Bahwa begitupun terhadap karyawan yang penggajiannya dengan sistem borongan, dan ternyata hasil borongan dalam 1 ( satu ) bulan, tidak mencapai UMK Kab. Pasuruan tahun {{tahun_umk_sekarang}}, maka Pihak Pertama akan memberikan tambahan upah sesuai dengan ketentuan UMK Kab. Pasuruan tahun {{tahun_umk_sekarang}}, akan tetapi tambahan upah tersebut juga merupakan hutang Pihak Pertama kepada Pihak Kedua.
  6. Bahwa terhadap hutang Pihak Pertama kepada Pihak Kedua sebagaimana disebutkan pada angka ke – 4 dan / atau ke – 5 diatas, Pihak Pertama dan Pihak Kedua sepakat menyelesaikan secara musyawarah dan penyelesaian dimaksud dituangkan dalam Perjanjian Bersama ( PB ) berikutnya.
